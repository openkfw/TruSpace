# Glossary

Definitions for terms used throughout the TruSpace documentation and application.

| Term | Definition |
|---|---|
| **Document** | A file that can be uploaded to a workspace — a text document, spreadsheet, presentation, or any other file type. Documents can be shared and collaborated on by users within a workspace. |
| **IPFS** | InterPlanetary File System — a distributed file system that allows users to store and share files in a decentralized manner. In TruSpace, documents are stored on IPFS, ensuring that they are accessible and secure. |
| **Perspective** | A view or representation of a document — a way to visualize or analyze its content. Perspectives can be AI-generated or created and managed by users, and offer insight from a specific angle (e.g. financial, legal). |
| **Tag** | A label added to a document to categorize it or make it easier to find. Tags can be created and managed by users and AI within a workspace. |
| **User** | An individual with an account on the TruSpace platform. Users can create workspaces, upload documents, and collaborate with other users. Each user has a unique username and password for authentication. |
| **Workspace** | A virtual space where users collaborate on documents — a project or team space where users share and work on documents together. Workspaces can be public or private. |
