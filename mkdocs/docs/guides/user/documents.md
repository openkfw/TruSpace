# Documents

Upload, organize, and manage your documents.

## Uploading Documents

### Drag and Drop

Simply drag files into the workspace area.

### Upload Button

1. Click **"Upload"**
2. Select files
3. Wait for processing

## Supported Formats

- **Documents**: PDF, DOCX, TXT, MD
- **Spreadsheets**: XLSX, CSV
- **Presentations**: PPTX
- **Images**: PNG, JPG, GIF

## Document Actions

- **View**: Open in viewer
- **Download**: Get original file
- **Share**: Via workspace membership
- **Delete**: Remove from workspace (irreversible — the document is permanently removed)

## Version History

Documents maintain version history in IPFS.

## Collaboration Features

TruSpace supports real-time collaboration on documents so teams can gain insights, share knowledge, and build on each other's work:

- **Tags** — Categorize documents to make them easier to find. Add a tag using the *+* icon in the document view.
- **Comments** — Provide feedback or ask questions on a document. Open the comment panel via the comment icon in the bottom-right of the document view; comments (and the full comment history) can be exported.
- **Perspectives** — In addition to [AI-generated perspectives](ai-features.md#ai-perspectives), users can add their own perspective on a document (e.g. a financial or legal point of view) from the perspectives section of the document view. This lets contributors with different areas of expertise add their insight directly to the document.
