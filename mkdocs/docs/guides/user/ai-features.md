# AI Features

TruSpace uses local AI for document analysis.

## AI Perspectives

After uploading a document, AI automatically generates:

- **Summary**: Key points overview
- **Analysis**: Detailed examination

Users can also select from a range of predefined perspectives or create custom ones tailored to their specific needs — useful for angles like financial, legal, or technical review. Users can additionally create their own (non-AI) perspectives to share insights based on their own expertise; see [Collaboration Features](documents.md#collaboration-features).

## Chat with Documents

1. Open a document
2. Use the chat interface
3. Ask questions about the content

This feature is built on [Open Web UI](https://openwebui.com/) and supports various (local) LLMs, letting you quickly retrieve information or clarify details without reading the entire document.
